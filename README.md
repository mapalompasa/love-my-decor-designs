# Love My Decor Designs® — Digital Portfolio & Booking Portal

A luxury, Awwwards-caliber digital portfolio and automated WhatsApp booking portal created for **Love My Decor Designs** (Founder & Creative Director: **Selina Machima**).

Designed to replicate the exact structural typography, 16-column grid layout, heavy 5px divider bars, and brutalist editorial aesthetic of [https://outfit.hellohello.is/](https://outfit.hellohello.is/), tailored into an opulent **"Dark Luxury"** mode.

## Key Features & Structural Architecture

1. **Massive Typographic Hero**:
   - Replicates the heavy sans-serif typography and tight kerning of `outfit.hellohello.is` (`text-[13vw] font-[900] tracking-tighter uppercase`).
   - Solid 5px structural horizontal cream dividing bar (`#ede4dd`).
   - 16-column editorial metadata grid highlighting founder credits, Lusaka coordinates, and brand manifesto.

2. **Curated Portfolio Archive (Solving Bride Social Media Fatigue)**:
   - Categorized cleanly into:
     - `Luxury Weddings (5)`
     - `Kitchen Parties (4)` *(opulent Zambian pre-wedding celebrations)*
     - `Corporate Galas (3)`
   - 16-column asymmetric grid cadence matching `outfit.hellohello.is`.
   - Real, authentic high-resolution event photography (no AI-generated imagery).
   - Dual-diagonal kinetic arrow hover effect.
   - Interactive Lightbox / Blueprint modal with floral breakdown, guest count, and direct WhatsApp inquiry.

3. **Integrated Brutalist Booking Portal**:
   - Captures: Event Type, Event Date, Venue / City, Guest Count, and Decor Budget Tier (`Signature Luxury`, `Opulent Couture`, `Royal Grandeur`).
   - **WhatsApp Automation**: On submission, auto-generates a formatted WhatsApp inquiry directed to **+260 979 176 151**.
   - Interactive on-screen dispatch receipt card with backup copy and launch triggers.

4. **Editorial Footer**:
   - Features Selina Machima's name in prominent typography, direct contacts, social links with custom inline SVGs (WhatsApp, Instagram, TikTok, Facebook, LinkedIn), and giant watermark typography.
